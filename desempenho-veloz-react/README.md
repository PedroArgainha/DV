# Desempenho Veloz — React

Projeto convertido dos três ficheiros HTML originais para React + Vite.

## Executar localmente

```bash
npm install
npm run dev
```

Abrir o endereço indicado pelo Vite, normalmente `http://localhost:5173`.

## Criar versão de produção

```bash
npm run build
npm run preview
```

A pasta final fica em `dist/`.
